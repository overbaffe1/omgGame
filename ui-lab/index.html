UI LAB · Dark Fantasy Atlas

Sprite-атлас в духе Diablo II, сгенерированный Aseprite (headless, собран из исходников) через MCP-сервер aseprite-mcp — 36 реальных вызова инструментов, ноль ручного рисования. Ниже — атлас в деле: 9-slice, состояния, тултипы, живые орбы.

Ι. СЦЕНА — «весь UI из одного PNG»

Всё внутри рамки нарисовано из atlas.png: панели и кнопки — 9-slice, орбы — спрайт + процедурная жидкость, шрифт — 4×5, курсор — спрайт из атласа. Кликай кнопки и слоты ремня (1–6). SLAY даёт золото и опыт, BLEED пугает орб жизни.

summoning atlas…

что здесь происходит

  • 9-slice — панели тянутся без потери пиксельных рамок (центр из slice-метаданных Aseprite)
  • состояния — btn_normal / btn_hover / btn_pressed — три региона одного атласа
  • орбы — круг-клип поверх спрайта, волна — синус, уровень — lerp к цели
  • тултипы — tooltip9 + пиксельный шрифт, позиция от слота
  • курсор — системный скрыт, рисуется спрайт cursor

попробуй

  • наведи на слоты ремня
  • SLAY ×N до LEVEL UP
  • BLEED — виньетка и отлив орба

ΙV. КОНВЕЙЕР — как это собрано

headless Aseprite 1.3.18.6 (собран из исходников, без UI/Skia)
        │
        ▼
@letsagents/aseprite-mcp  ·  76 инструментов, stdio JSON-RPC
        │   create_canvas · set_palette · add_layer ×6 · edit_sprite ×26
        │   script_execute (slices) · spritesheet_export
        ▼
ui-lab/assets/atlas.aseprite  →  atlas.png (512×384) + atlas.json (26 slices)

Перегенерировать: node tools/gen-atlas.mjs (нужен бинарь Aseprite: ASEPRITE_PATH=…; сборка headless-версии — tools/ensure-aseprite-headless.sh).

Слои исходника: misc · stone · buttons · orbs · slots · icons — каждый регион рисуется батчами примитивов (edit_sprite) поверх палитры из 35 цветов.
