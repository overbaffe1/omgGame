# Спичка

![Три кадра: заставка, коробка, дым](media/banner.jpg)

Короткий вертикальный фильм, целиком нарисованный и озвученный в JavaScript.
Ни одной картинки, ни одного звукового файла — в том же духе, что [procedural-film](https://github.com/kuhnhomeuk-cell/procedural-film), только своя история.

Спичка живёт три секунды. Этого хватает, чтобы зажечь другую.

34 секунды, 8 кадров, 96 bpm, 1080×1920. Бумага и тушь, чертёж, удар, пламя, стол, дым. В конце можно зажечь свою: провести головкой по тёрке и донести огонь до свечи.

## Как смотреть

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8080
```

Открой `http://localhost:8080`.

Звук включается по нажатию — браузер иначе не отдаёт Web Audio. Пробел ставит на паузу, стрелки перематывают, клавиши 1–8 прыгают по кадрам.

`?t=16.5` открывает фильм с этого момента. `?shot=flame` — середина кадра.

## МИША ПРОТИВ ВСЕГО 🥊

Новое: [`film/misha.html`](film/misha.html) — эпичный мем-боевичок, 5:02, горизонтальный 16:9.
Миша варит суп, из супа выпрыгивает бактерия — и понеслось: таракан (тапок-бумеранг), кот
(апперкот «на балкон»), гусь с подкреплением, медведь (бросок через бедро), гопник на трибуне
стадиона, ти-рекс, МЕГА БОСС ДЕД (веник, тапки-самолёты, суперсая и… суп), планета Земля
и галактика — апперкотом. 10 раундов, HP-бары, комбо-счётчик, финишеры с баннерами,
процедурный фонк-бит (WebAudio) и закадровый комментатор. Каждый кадр — чистая функция
времени: можно перематывать и записать `.webm` кнопкой ⏺.

| файл | что делает |
|---|---|
| `film/misha.html` | страница фильма: канвас 1920×1080 + плеер |
| `film/misha3d.js` | ядро 3D: риг Миши, библиотека ударов, камера-шоты, частицы |
| `film/misha-things.js` | враги: бактерия, инфузории, таракан, кот, гуси, медведь, гопник, Ти-Рекс, ДЕД, Земля, галактика |
| `film/misha-worlds.js` | миры: кухня с супом, микромир, двор, парк, лес, стадион с трибунами, дача, космос |
| `film/misha-rounds.js` | сценарий: 12 сцен, биты хореографии, шоты камеры, субтитры |
| `film/misha-film.js` | кадр, HUD (HP-бары, комбо, урон, баннеры), фонк-саундтрек, SFX, голос |
| `film/misha-voices/*.mp3` | 10 реплик комментатора |
| `film/misha.mp4` | **готовый рендер**: 5:03, 1920×1080, 24fps, H.264 + AAC (звук вшит) — [скачать](film/misha.mp4) |
| `film/render/` | офлайн-пайплайн рендера в MP4: программный растеризатор + WebAudio-DSP + ffmpeg |

## Мультфильм о @body51

Отдельная вещь: [`film/body51.html`](film/body51.html) — «Вайбкодер из Мурманска», процедурный мультфильм
по фактам стримов: 12 глав, 3:55, вертикальный мастер 9:16. Картинка и музыка — код, закадровый голос — рассказчик,
реплики Артёма — дословно по субтитрам. Готовый MP4 — `film/body51.mp4`, разбор источников — [`body51/multik.md`](body51/multik.md).
Новая минутная история — **«Один день Артёма»**, 10 сцен, 1:33, рисованный 2D-мульт, 60 fps: режиссёрская версия с крупными планами, мимикой, тремя играми и внешностью по референсу: [`film/body51-min.html`](film/body51-min.html), ролик — `film/body51-min.mp4`.

## Мультик по фактам: «Вайбкодер из Мурманска»

Отдельная вещь — вертикальный мультфильм про инди-разработчика [@body51](https://youtube.com/@body51):
10 лет без релиза, лысый кот Гуччи, автокормушка Валера, лимиты Codex
и 13 500 вишлистов, которые свалились случайно. 12 глав, 3:55, 1080×1920.

Картинка рисуется кодом, музыка синтезируется — как и остальное кино в этом репозитории.
Голос за кадром — рассказчик; реплики Артёма звучат только титрами, дословно по субтитрам стримов.
