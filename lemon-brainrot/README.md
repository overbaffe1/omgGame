# ЛИМОННЫЙ БРЕЙНРОТ 🍋

Мем-шорт для YouTube в духе скибиди-итальянского-брейнрот-эстетика:
**каждый кадр нарисован в JavaScript на canvas, каждый звук синтезирован в
Web Audio**, и всё это можно записать в WebM прямо из браузера и залить на
YouTube Shorts.

38 секунд, вертикаль 9:16, 13 планов: скрим-хук, титры, танцующий
ЛИМОНЕЛЛО КАПУЧИНЕЛЛО, скибиди-туалет с лимонной головой, ЛИМОНЧЕЛЛО
ПАРОТТО, кайдзю-лимон над городом, БИТВА ВЕКА с лазерами, магия «6-7»,
конвейер с лимоном-самозванцем в костюме апельсина, дискотека, предельная
форма, VS-карточка и финальный «ПОДПИШИСЬ».

## Как смотреть и записать

1. Открой [`dist/lemon-brainrot.html`](dist/lemon-brainrot.html) в браузере
   (двойной клик по файлу — ничего ставить не нужно).
2. Нажми **▶ Смотреть**.
3. Нужен файл для YouTube? Нажми **⏺ Записать WebM** — фильм проиграется
   один раз от начала до конца и скачается как `lemon-brainrot.webm`
   (YouTube принимает WebM; длительность записи = реальное время, 38 с).
4. Залей на YouTube Shorts: вертикальный формат уже правильный.

Горячие клавиши: пробел — пауза, `←` `→` — ±2 с, `M` — звук, `R` — сначала,
`F` — во весь экран.

## Как это устроено

Тот же контракт, что и в `the-deep/`: сцена — чистая функция от времени,
случайность — только из сидированного ГПСЧ, всё собирается в один HTML-файл.

```
lemon-brainrot/
  index.html            оболочка-плеер с кнопкой записи WebM
  src/engine.js         рантайм FILM: таймлайн, renderFrame(T), переходы
  src/lib.js            мем-инструменты: impact-текст, лучи, взрывы, лимоны,
                        унитаз, вертолёт, тряска, zoom-панчи
  src/timeline.js       13 планов, 150 bpm (доля = 0.4 с)
  src/scenes/01..13     по файлу на план
  src/music.js          хардбэйс-турбо бит + робо-чанты «СКИ-БИ-ДИ ДОП ДОП»
                        на формантном синтезе (голос из осцилляторов!)
  src/player.js         плеер + MediaRecorder: canvas-стрим + звук → WebM
  tools/build.mjs       dist/lemon-brainrot.html
  tools/smoke.mjs       гейт: рендер всех планов в Node, детерминизм
```

## Проверка и сборка

```
node tools/smoke.mjs    # гейт (13 планов, границы, детерминизм)
node tools/build.mjs    # dist/lemon-brainrot.html
```

## Заметки

- Все персонажи, тексты и музыка — оригинальные; заимствована только
  грамматика жанра (абсурдные гибриды, ритмические чанты, слэм-монтаж).
- Формантный синтез в `music.js` буквально «поёт» слоги осцилляторами —
  никаких сэмплов.
- Запись WebM идёт в реальном времени: 38 секунд фильма = 38 секунд записи.
