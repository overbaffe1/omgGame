# ВКР: интеллектуальная справочная система ПсковГУ (RAG + LLM) — 3D-презентация

9 слайдов, светлая тема, для курса «Системный анализ и моделирование интеллектуальных систем».
На слайдах настоящие 3D-модели PowerPoint с встроенной анимацией (skinned glTF) и Morph-переходами.

- Сборка: `node build.js` (движок — `../schumpeter/lib.js` + `pptx3d.js`, окружение — `../tools/setup-env.sh`), превью: `node build.js --preview`.
- Модели: `LD_LIBRARY_PATH=/tmp/bstub python3 models/make_vkr_models.py [chat search target people gears gpu gauge rocket]`
  (хелперы из `../schumpeter/models`, костная анимация — `../cantillon/models/rig.py`).
- Фоновые ассеты (ореол, тень): `python3 stage.py`. Заметки докладчика — `notes.js`.
- Результат: `exports/vkr-rag-pskgu.pptx`, текст выступления `exports/vkr-rag-pskgu-tekst.md`,
  превью анимаций `exports/vkr-rag-3d-animations-preview.gif`.
