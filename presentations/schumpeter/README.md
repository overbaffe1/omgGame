# Шумпетер: 3D-презентация

Результат: `exports/schumpeter-3d-presentation.pptx`. Это 15 слайдов 16:9 с редактируемым текстом, заметками докладчика и переходами Morph (если Morph не поддерживается, вместо него будет Fade).

| | |
|---|---|
| `raw/` | исходные 3D-рендеры |
| `src/` | портрет около 1910 года (Wikimedia Commons, общественное достояние) |
| `compose.py` | собирает из рендеров фоны 1920×1080 с градиентом под текст и кладёт их в `assets/` |
| `lib.js` | общий слой разметки: из одного описания слайда получаются .pptx (pptxgenjs) и HTML-превью |
| `build.js` | содержание всех слайдов и текст для докладчика |

```bash
npm install
python3 compose.py        # только если менялись рендеры
node build.js             # собрать .pptx
node build.js --preview   # плюс PNG-превью в preview/ (headless Chromium)
```

Шрифты Georgia и Arial есть в Windows и macOS. В превью вместо них стоят Noto Serif и Arimo: метрики у них близкие или чуть шире, поэтому, если текст помещается в превью, он поместится и в PowerPoint.
