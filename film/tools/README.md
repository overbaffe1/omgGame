# Мультфильм «Вайбкодер из Мурманска» (`film/body51.html`)

Вертикальный (9:16, 1080×1920) процедурный мультфильм по фактам стримов `@body51`.
12 глав, 3:55 (фаст-мемный закадровый текст). Картинка рисуется кодом: собственный 3D-движок (полигоны, мягкий свет,
туман, экраны как 2D-содержимое на 3D-плоскостях). Музыка синтезируется.
Два голоса: закадровый рассказчик (`body51-voices/n01…n10.mp3`) и второй, отдельный
синтетический голос для цитат (`body51-voices/q01…q09.mp3`) — дословно по субтитрам.
Голос самого Артёма не синтезируется и не имитируется.

## Из чего собрано

| файл | что делает |
|---|---|
| `film/body51.html` | страница: канвас + плеер (перемотка, главы, запись `.webm`, ссылка на MP4) |
| `film/body51-film.js` | база кадра: палитра, падающий снег, северное сияние, HUD главы, субтитры рассказчика, титры цитат |
| `film/body51-3d.js` | движок 3D: математика (векторы/матрицы), примитивы (`box/sphere/prism/torus/cone/wall/slab`), класс `Scene` (камера, фрустум-клип, painter-сортировка, туман, блики, тени), риги `rigPerson`/`rigCat`, 2D-содержимое на 3D-плоскости (`scene.screen`) |
| `film/body51-3d-scenes.js` | 12 глав в 3D: комнаты, дворы, дюны; каждая возвращает 2D-экраны, квады окон и «блики» для свечения |
| `film/body51-scenes.js` | 12 сцен плоской (2D) версии — остаются фолбэком, если 3D-движок не загрузился |
| `film/body51-score.js` | партитура: чистая математика, выдаёт список нот (используется и браузером, и рендером) |
| `film/body51-run.js` | кадр, звук, запуск плеера; в Node экспортирует `__body51.frame(t)` |
| `film/body51-timing.js` | **собранный** хронометраж: длительности глав и текст рассказчика для субтитров |
| `film/body51-voices/script.json` | сценарий: тексты закадровых реплик и их привязка к главам |
| `film/body51-voices/n01…n10.mp3` | озвучка рассказчика (по клипу на главу) |
| `film/body51-voices/q01…q09.mp3` | озвучка цитат вторым голосом (по блоку на главу) |
| `film/body51.mp4` | готовый ролик: 1080×1920, 24 fps, 3D, два голоса + музыка, 3:55 (после правок пересобирай: `render_body51.mjs --jobs`) |

## Как править

1. Текст рассказчика (`voices`) и блоки цитат (`quotes`) — `film/body51-voices/script.json`.
   Цитаты озвучиваются отдельным голосом в файлы `qNN.mp3`; блок цитат идёт после
   рассказчика (`QGAP` = 0,9 с паузы, `QAT` = 0,35 с — отступ), длительность главы
   считается из суммы: `LEAD + рассказчик + QGAP + цитата + TAIL` (`tools/body51_timing.mjs`).
   Если `qNN.mp3` нет и указан `--no-voice`, длина берётся оценкой по скорости речи.
2. Синхронизация титров: `tools/body51_speech.mjs` находит в озвучке паузы (`silencedetect`)
   и раскладывает фразы по отрезкам речи — титры пишутся не «по длине строки», а по реальному
   чтению. Заодно из файла берётся тишина в начале/конце, поэтому голос в фильме начинается
   ровно там, где написан таймингом, и не «обрезается раньше или позже».

3. Длительности глав считаются из mp3 (или из скорости речи 12,7 симв/сек, если озвучки ещё нет):
   ```bash
   node film/tools/build_body51_timing.mjs      # → film/body51-timing.js
   ```
   Хронометраж печатается в консоль — удобно проверять, что субтитры не налезают на реплики.
4. Проверка кадров без полного рендера:
   ```bash
   node film/tools/render_body51.mjs --shots auto          # по кадру из каждой главы → /tmp/body51-shots
   node film/tools/render_body51.mjs --shots 0,60,190      # конкретные секунды
   node film/tools/render_body51.mjs --range 30:60 --fast  # кусок видео (и звук) для проверки правки
   ```

   Сцены 3D — отдельный файл `film/body51-3d-scenes.js`: каждая глава возвращает
   `{probe, monitor, screens, winQuad, cards, glows}` — «пробу» для проверки крупности,
   квады 2D-экранов и точки свечения. Быстрая проверка без полного рендера:
   `node /tmp/bench/frame.js` (пиксели на метр, положение центра) — так подбирается крупность.
   ```
5. Полный рендер — **на своей машине это в разы быстрее**, поэтому есть параллельный режим
   (по умолчанию один процесс; `--jobs N` режет фильм на N кусков, рендерит их разом и склеивает):
   ```bash
   DEPS=$(bash film/tools/body51_deps.sh)
   BODY51_DEPS=$DEPS node film/tools/render_body51.mjs --jobs 8        # 8 ядер → примерно в 8 раз быстрее
   BODY51_DEPS=$DEPS node film/tools/render_body51.mjs --jobs 8 --range 0:60   # только кусок
   ```
   Куски нарезаются по кадрам (без дрожания на стыках), аудио добавляется один раз при склейке.

6. Старый (последовательный) полный рендер:
   ```bash
   DEPS=$(bash film/tools/body51_deps.sh)                  # @napi-rs/canvas + ffmpeg-static в /tmp/body51-deps
   BODY51_DEPS=$DEPS node film/tools/render_body51.mjs     # → film/body51.mp4 (~15–20 минут)
   ```
   Полезные переменные: `BODY51_OUT` (куда писать MP4), `BODY51_AUDIO` (готовый WAV вместо сборки),
   `FFMPEG_BIN`, `--crf 21` (по умолчанию 21; больше значение — меньше файл), `--fast` (без второй проходки bloom),
   `--no-voice` (примерка кадров без озвучки — длительности считаются по скорости речи).
   Длительность видео и звука берётся из `body51-timing.js`, поэтому картинка и музыка всегда синхронны.

## Минутная мем-версия

Отдельная короткая история — 6 глав, около 1:01 (новый сценарий, не перемонтаж прежней минутной версии):

```bash
DEPS=$(bash film/tools/body51_deps.sh)
BODY51_DEPS=$DEPS node film/tools/render_body51.mjs --cut minute --jobs 8
```

`--cut` пробрасывается воркерам `--jobs` — они рендерят кадры той же нарезки
(если забыть, видео соберётся от полной версии, а звук — от нарезки).

Сюжет проходит через Гуччи и автокормушку Валеру, Desktop Hellfarmer и первые копии в Японии,
Backpack Inspector, White Meridian и хлебную идею, перерыв на турнике и карточку трёх проектов.
Сцены и персонажи короткой версии рисуются и анимируются вручную на Canvas; стример — векторная
стилизация по фото-референсу, само фото в ролик не загружается. Титры и графика остаются внутри
вертикального кадра. Озвучка — `m11…m16.mp3`; цитата q02 — дословная, с номером стрима.
Текст лежит в `film/body51-voices/script-minute.json`, тайминг собирается из mp3 в
`film/body51-timing-min.js`, ролик — `film/body51-min.mp4`, страница — `film/body51-min.html`.
Для монтажных акцентов остаются короткая мем-тряска на склейках и финальная карточка.
Цитаты в нарезке используют тот же аудиофайл `q02.mp3`, что и в полной версии.
Сверка синхрона: `node film/tools/check_body51_sync.mjs --cut minute`.

## Синхронизация озвучки

После рендера полезно сверить, что каждая реплика звучит ровно там, где написано в тайминге:

```bash
FFMPEG_BIN=/путь/к/ffmpeg node film/tools/check_body51_sync.mjs            # сверить film/body51.mp4
FFMPEG_BIN=/путь/к/ffmpeg node film/tools/check_body51_sync.mjs --mp4 /tmp/кусок.mp4 --offset 120
```

Скрипт вырезает кусок вокруг ожидаемого места реплики и корреляцией ищет, где голос
звучит на самом деле; печатает сдвиг в секундах и «✓/✗». Такое же выравнивание делает
`tools/body51_speech.mjs` при сборке таймингов: из mp3 берутся паузы, фразы раскладываются
по отрезкам речи, поэтому субтитры не отстают и не убегают.

## Про MP4 в репозитории

`film/body51.mp4` и `film/body51-min.mp4` собраны офлайн из текущего кода (полная версия — 3:55,
короткая версия — около 1:01). Полный рендер тяжёлый (в этой песочнице 2 ядра, ~15 минут
с `--jobs 2`), поэтому после правок текста/озвучки пересобирай MP4 локально, где `--jobs`
ускоряет сборку почти линейно по числу ядер:

```bash
DEPS=$(bash film/tools/body51_deps.sh)
BODY51_DEPS=$DEPS node film/tools/render_body51.mjs --jobs $(nproc)                 # полная версия → film/body51.mp4
BODY51_DEPS=$DEPS node film/tools/render_body51.mjs --cut minute --jobs $(nproc)   # минутная → film/body51-min.mp4
```

## Правила монтажа (важные)

- В кадре **нет** синтезированного голоса Артёма. Реплики — только титрами, дословно по субтитрам,
  с указанием номера стрима.
- Не используются личные темы: долги, здоровье, семья, отношения. См. `body51/facts.md` (метки ⚠)
  и раздел «НЕ использовать» в `body51/meme-bible.md`.
- Факты в главах — из `body51/facts.md`, `body51/best_moments.md` и `body51/hl/NNN_ID.md`.
- Титр «ЗА КАДРОМ» — речь рассказчика; подпись `#NNN — дословно` — речь Артёма.

## Проверено

- Кадры: `film/tools/render_body51.mjs --shots auto` — по одному кадру на главу, все 12 сцен без наложений текста.
- Хронометраж: 3:55 (полная версия) и 1:01 (короткая версия) при озвучке из `body51-voices/*.mp3`.
- MP4: 1080×1920, 24 fps, h264 + AAC, `+faststart`, пик звука −1.0 дБ (можно лить на YouTube как Shorts или обычное видео).
- Синхрон: `check_body51_sync.mjs` и `check_body51_sync.mjs --cut minute` — все реплики сходятся с таймингом в пределах ±0.05 с.
