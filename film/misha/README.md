# МИША против всего

5-минутный экшен-ролик (9:16) в процедурном 3D: Миша дерётся с бактерией, амёбой, мухой, котом,
акулой, Т-Рексом, китом, планетой, Дедом (финальный босс), Солнцем и галактикой.
Картинка рисуется кодом (полигоны, туман, свет — тот же движок, что в `film/body51-3d.js`),
звук синтезируется кодом из тех же ударов. Внешних картинок, видео и аудио нет.

## Смотреть в браузере (без звука)

Из корня репозитория:

```bash
python3 -m http.server 8080
```

Открыть `http://localhost:8080/film/misha/` (пробел — пауза, `?t=120` — с 2:00).

## Рендер в MP4 (со звуком), 5:00

Один раз (зависимости из npm):

```bash
mkdir -p ~/misha-deps && cd ~/misha-deps && npm i @napi-rs/canvas @ffmpeg-installer/ffmpeg
export MISHA_DEPS=~/misha-deps/node_modules
```

Затем из корня репозитория:

```bash
node film/misha/render.mjs                    # полный ролик 720×1280 → film/misha/out/misha.mp4
node film/misha/render.mjs --size 1080x1920   # полное HD, дольше
node film/misha/render.mjs --shots 10,60,150  # только PNG-кадры для проверки
node film/misha/render.mjs --from 0 --to 30   # кусок
```

Папка `film/misha/out/` в `.gitignore`: ролик и кадры в Git не попадают.

## Файлы

| файл | что делает |
|---|---|
| `misha.js` | таймлайн (13 этапов, 300 с), сцены, риг Миши, враги, титры, удары |
| `render.mjs` | офлайн-рендер: кадры → ffmpeg, звук синтезируется из `HITS` и `STAGES` |
| `index.html` | браузерный просмотр с ползунком |

## Как править

- Титры: `C(t0, t1, 'текст', 'bottom'|'top'|'center', big)` в `misha.js`.
- Удары (вспышка, тряска, слово на экране и звук): `HIT(t, 'hit'|'big'|'whoosh', 'СЛОВО')`.
- Этапы и громкость музыки: массив `STAGES`. Длины этапов должны в сумме давать 300 с.
- Сцены: функции `sBact`, `sAmoeba`, … `sGalaxy`, `sFinale`.

## Ограничения

Стилизованная низкополигональная графика, не фотореализм. Сцены собраны из примитивов, поэтому
«как в Мортал Комбат» здесь не получится. Звук — синтез (бит, бас, пэд, удары), без голоса.
