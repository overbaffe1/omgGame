# Великий суп — операция: обед

Самостоятельная 2.5D мем-пародия: **86 секунд, 1920×1080, 60 fps**.

Референс пользователя — [«О великий суп наварили»](https://www.youtube.com/watch?v=OBg9ZAqBifQ). Пользователь выбрал отдельный фильм, без Артёма и Гуччи, с новой музыкой и репликами. Исходные кадры, запись хора и мелодия не используются. Это не покадровый пересказ референса.

Неофициальная научно-фантастическая фан-пародия; не продукция Games Workshop и не заявление об их одобрении. Иллюстрации созданы заново, с кухонной геральдикой. Реплики авторские, не цитаты из исходного песнопения.

## Изображение и звук

`assets/*.png` — новые сгенерированные исходные иллюстрации. `assets/cut` — прозрачные объекты и части персонажа; маски воспроизводятся скриптом. В анимации независимо двигаются голова и предплечья, половник привязан к кисти, пар/ингредиенты/корабли/соль рисуются и перемещаются кодом. Крупный план командира поставлен отдельно. Намеренные влёты и кадрирование плеч — часть постановки.

Голос **voice-01** выбран пользователем. Девять записей `voices/p*.mp3`; обычная речь, не пение и не клон реального человека.

Музыка — новая партитура в ре миноре, 96 BPM: `music/score.json`. Синтезатор [TinySoundFont](https://github.com/schellingb/TinySoundFont), MIT; заголовок и лицензия в `film/tools/vendor`. Тембры [GeneralUser GS](https://github.com/mrbumpy409/GeneralUser-GS), автор S. Christian Collins. Полная лицензия, включая сведения автора о происхождении семплов, сохранена в `music/GeneralUser-GS-LICENSE.txt`. Банк разрешён автором для музыкальных записей; мы не объявляем его семплы своей собственностью. SF2 хранится вне Git.

Foley — собственные синтезированные шорохи, удары, металл и воздушные пролёты. Голос и музыка смешиваются раздельно; перед «Недосолено» подложка намеренно замолкает. Цель микса −16 LUFS / −1,5 dBTP. Шрифты Manrope и PT Serif, SIL OFL.

## Восстановление и сборка

Команды из корня репозитория; нужны Node, GCC, Python и `gh`.

```bash
npm i --prefix /tmp/soup-deps @napi-rs/canvas @ffmpeg-installer/ffmpeg @ffprobe-installer/ffprobe
mkdir -p /tmp/soup-music
gh api -H 'Accept: application/vnd.github.raw+json' repos/mrbumpy409/GeneralUser-GS/contents/GeneralUser-GS.sf2 > /tmp/soup-music/GeneralUser-GS.sf2
SOUP_DEPS=/tmp/soup-deps/node_modules node film/tools/prepare_great_soup_assets.mjs
SOUP_DEPS=/tmp/soup-deps/node_modules node film/tools/build_great_soup_audio.mjs
SOUP_DEPS=/tmp/soup-deps/node_modules node film/tools/render_great_soup.mjs --jobs 2
SOUP_DEPS=/tmp/soup-deps/node_modules node film/tools/check_great_soup.mjs
python3 film/tools/serve_great_soup.py --port 8081
```

Не добавляйте SF2, WAV, F32 и зависимости в Git. Плеер работает с готовым MP4; `?live=1` включает живые слои с тем же миксом. Материалы и предыдущий фильм про Артёма не изменены.
