# «Вайбкодер из Мурманска» — мультфильм по фактам стримов

Процедурный вертикальный мультфильм о **@body51** (Артём, Мурманск): 12 глав, 5 минут 52 секунды, 1080×1920, 24 кадра/с.
Картинка нарисована кодом — собственный 3D-движок (полигоны, мягкий свет, туман, объёмные декорации),
музыка синтезирована. Два голоса: закадровый рассказчик и второй, отдельный синтетический голос для цитат.
Реплики Артёма в кадре — **дословно по субтитрам стримов**, без выдуманных фраз; голос Артёма не синтезируется.

## Из чего собрано

| файл | что делает |
|---|---|
| `film/body51.html` | страница мультфильма: canvas 1080×1920 + общий плеер `player.js` и пост-обработка `fx.js` |
| `film/body51-timing.js` | хронометраж глав (собирается автоматически по длительности озвучки) |
| `film/body51-film.js` | база кадра: палитра, северное сияние, персонажи, интерфейс главы, субтитры рассказчика |
| `film/body51-scenes.js` | 12 сцен мультфильма |
| `film/body51-score.js` | партитура: чистая математика, из неё и браузер, и офлайн-рендер |
| `film/body51-run.js` | кадр + звук + запуск плеера |
| `film/body51-voices/script.json` | текст рассказчика по главам |
| `film/body51-voices/n01…n10.mp3` | закадровый голос (синтез), **не** голос Артёма |
| `film/tools/body51_timing.mjs` | расчёт длительностей (12,7 симв/сек — калибровка по голосам «Анатомии страсти») |
| `film/tools/build_body51_timing.mjs` | пересобрать `body51-timing.js` |
| `film/tools/render_body51.mjs` | офлайн-рендер MP4 (кадры в ffmpeg, микс голоса и музыки) |

## Как пересобрать

```bash
# 1) зависимости рендера (в любом месте вне репозитория)
npm i @napi-rs/canvas @ffmpeg-installer/ffmpeg

# 2) хронометраж по длительности mp3
node film/tools/build_body51_timing.mjs

# 3) проверка кадров (раскадровка в /tmp/body51-shots)
node film/tools/render_body51.mjs --shots auto
node film/tools/render_body51.mjs --shots 22,120,265

# 4) полный MP4 → film/body51.mp4
node film/tools/render_body51.mjs
#    или кусок для правки: --range 30:60 · BODY51_OUT=/tmp/test.mp4
```

Если `@napi-rs/canvas` установить нельзя — анимированную версию можно посмотреть в браузере:
`python3 -m http.server 8080` и открыть `/film/body51.html`. Плеер умеет записывать `.webm` кнопкой ⏺.

## Звук

- **Музыка** — только синтез: пэд, бас, арпеджио и колокольчики в ля-миноре с переходом на мажор в главе о релизе; под репликами рассказчика музыка приглушается.
- **Голос** — выбранный в Arena рассказчик, синтез речи; в кадре подписан как «ЗА КАДРОМ».
- **Реплики Артёма** — субтитры-цитаты. Синтезированного «голоса Артёма» в мультфильме нет: подделывать его голос было бы нечестно, а фразы он говорит сам, их можно найти по ссылкам в `meme-video-cut.md`.
