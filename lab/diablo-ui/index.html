3 · КАК ЭТО СОБРАНО · ASEPRITE MCP

Скрипт generate_atlas.py эмулирует работу Aseprite через MCP: создаёт слои, рисует камень/золото, экспортирует лист. Повтори у себя.

MCP workflow (псевдо)совместимо с aseprite-mcp / Claude MCP
# 1. Установка
pip install Pillow
# в Aseprite: включить CLI, палитра diablo.gpl

# 2. MCP вызовы (эмулируются Python-скриптом)
mcp.aseprite_create_document(1024,1024, "DiabloAtlas")
mcp.aseprite_create_layer("Stone")
mcp.aseprite_set_palette(["#1a1410","#c9a84c","#7a1a1a","#e8dcc0","#2a5ac4"])
mcp.aseprite_draw_rect("Stone", x=16,y=16,w=208,h=52, gradient="#2c2218→#16100a")
mcp.aseprite_draw_bevel("Gold", x=16,y=16,w=208,h=52, rivets=true)
# ... повторить для 54 спрайтов (см. generate_atlas.py)

# 3. Экспорт
aseprite --batch atlas.ase --sheet atlas.png \
  --data atlas.json --sheet-type packed \
  --sheet-width 1024 --sheet-height 1024 --inner-padding 0

# 4. Проверка
python generate_atlas.py  # наш эмулятор делает то же без Aseprite
open lab/diablo-ui/index.html

Реальный generate_atlas.py в папке проекта рисует всё процедурно: градиенты камня, фаски золота, шум, клёпки, жидкости сфер. Без внешних картинок — только Pillow.
