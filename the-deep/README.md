# ГЛУБИНА · THE DEEP

Процедурный фильм: погружение от зеркала океана до дна жёлоба.
**Каждый кадр нарисован в JavaScript на canvas, каждый звук синтезирован в Web Audio.**
Ноль медиафайлов — ни картинок, ни видео, ни аудио в репозитории.

Вдохновлено [kuhnhomeuk-cell/procedural-film](https://github.com/kuhnhomeuk-cell/procedural-film) —
их «жизнь монарха» показала, что короткий метр можно пересобрать из чистого кода.
Это самостоятельный фильм со своей механикой: не жизненный цикл, а вертикальное
погружение по зонам океана.

## Смотреть

Самодостаточный плеер: [`dist/the-deep.html`](dist/the-deep.html) — просто откройте
файлом в браузере (двойной клик). Ничего устанавливать не нужно.

Либо в режиме разработки:

```
cd the-deep
python3 -m http.server 8080
# http://localhost:8080/
```

**Управление:** пробел — пауза, `←` `→` — ±2 с, `M` — звук, `R` — сначала, `F` — во весь экран.

## Как это устроено

Схема повторяет контракт procedural-film: сцена — чистая функция от времени,
случайность — только из сидированного ГПСЧ, всё собирается в один HTML-файл.

```
the-deep/
  index.html            оболочка-плеер (режим разработки, грузит src/)
  src/engine.js         рантайм FILM: реестр сцен, таймлайн, renderFrame(T),
                        переходы (cut/fade), зерно + виньетка на выходе
  src/lib.js            ящик инструментов: rng/hash/noise, палитра, медузы,
                        рыбы, каустика, лучи, чертёжная сетка, текст с автофитом
  src/timeline.js       раскадровка: 12 планов + метаданные
  src/scenes/01..12     по одному файлу на план; draw(t, info) — чистая отрисовка
  src/music.js          саундтрек: OfflineAudioContext, осцилляторы + шум +
                        свёрточная реверберация; щелчок удильщика, пинки сонара
  src/player.js         chrome плеера: play/scrub/mute, часы по аудио, rAF-цикл
  tools/build.mjs       склеивает всё в dist/the-deep.html
  tools/smoke.mjs       гейт: рендер всех планов в Node на мок-канвасе, ловит
                        ошибки отрисовки, дыры таймлайна и недетерминизм
```

Ключевые правила, из-за которых фильм вообще можно пересобрать кадр в кадр:

- `draw(t, info)` не хранит состояния между кадрами — можно перематывать;
- `renderFrame(T)` — чистая функция от T; зерно привязано к номеру кадра;
- случайность только `FILM.lib.rng(seed)` / `FILM.lib.hash(...)`;
- саундтрек рендерится один раз офлайн, потом просто играет с нужного смещения —
  поэтому скраб и звук всегда совпадают.

## Структура фильма

| T | План | Что происходит |
| --- | --- | --- |
| 0:00 | Зеркало | Рассветные волны сверху, заголовок влетает на бите |
| 0:03 | Свет | Взгляд вверх: зеркало воды, лучи, силуэты рыб, пузыри |
| 0:05 | Риф | Кораллы, водоросли, две стайки, медленный наезд |
| 0:08 | Спуск | Вода темнеет, медуза тонет, линейка глубины тикает 40–200 м |
| 0:11 | Сияние | Цветение лунных медуз, звон колоколов на каждый бит |
| 0:14 | Разрез | Синька: пять зон океана и путь погружения |
| 0:17 | Образец | Синька: рыба-удильщик с выносками |
| 0:19 | Удочка | Почти темнота, приманка светится, щелчок на 0:21 |
| 0:22 | Кит | Скелет кита на абиссальной равнине, падает снег |
| 0:25 | Курильщик | Чёрный курильщик, трубчатые черви, жар у основания |
| 0:29 | Жёлоб | Батискаф прожекторами по стенкам, 10 935 м |
| 0:33 | Конец | Пузыри, титры, «КОНЕЦ» на последних долях |

Подробности монтажа и музыкальной сетки — в [`storyboard.md`](storyboard.md).

## Проверка и сборка

```
node tools/smoke.mjs    # гейт: 12 планов, границы, детерминизм
node tools/build.mjs    # dist/the-deep.html
```

## Кредиты

Идея и дисциплина «фильм как код» — [procedural-film](https://github.com/kuhnhomeuk-cell/procedural-film)
(MIT), референс-фильм авторов: «The life of a monarch butterfly», смоделированный
на «The life of a fruit fly» Кевина Нго. Здесь — своя режиссура, своя графика,
своя музыка и свой движок; от исходника взята только форма подачи.
